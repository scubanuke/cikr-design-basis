# CIKR Design Basis Examples

A public site showing one worked design basis example for each critical infrastructure sector: the sector framework, one facility class, one use case (summary card only) and one real reference event. Owned by Project 0 (Cross-Project Alignment) of Tim Roxey's *Design Basis for AI Governance in Critical Infrastructure* (Eclectic Technologies).

Every document the site links to is frozen in *CIKR Design Basis Examples, Edition 2 (November 2026)*, deposited in four Zenodo records: a new version of the edition record (concept DOI 10.5281/zenodo.23863985), holding the thirty-one sector framework and facility-class documents, and three collections of reference events by sector family (Lifelines; Public Safety and Government; Industry and Economy). The PDFs are served from the publications mirror at `scubanuke.github.io/publications/cikr/edition-2/`, with the reference events in a folder per collection. Edition 1 (version DOI 10.5281/zenodo.23863986) stays citable for what it contains. No use case is published; use cases are available to defenders and regulators on request.

## How the site is built

The HTML at the repository root is generated. Edit the sources in `content/` and run `python3 tools/build.py` from the repository root. The build reads the shared glossary terms from `glossary.json` in the `foundational-definitions` repository, so that repository must be checked out beside this one; a glossary entry here that carries `fd` takes its definition from there. The build also writes `reference-events.html`, the register of every reference event in the edition, and a page for each event under `events/`, from `content/register/events.json` and `content/register/tiers.json`. `events.json` is extracted at each freeze by `tools/extract_register.py` from Project 11's register cards and the Annex A of each frozen public edition; `tiers.json` holds each event's label in the four-label tier vocabulary. The featured card on each sector page keeps its **Date** and **Tier** lines.

`content/cards/` holds the public text of the sector cards, copied from Project 0's card drafts with the checker notes removed. `content/facility_classes.json` holds each sector's other facility classes, titles only, generated from the DBA Facility Class Register; it is not part of the frozen edition. `content/readers.json`, `content/pages.json` and `content/glossary.json` hold the reader pages, the fixed pages and the glossary. `assets/figures/` holds the two figures; `tools/make_layers_figure.py` draws the simplified design basis layers figure.

The edition's DOIs sit at the top of `tools/build.py`: `VERSION_DOI` for the edition record and one version and concept DOI per collection in `COLLECTIONS`. Until they are filled the pages say "DOI pending", and `FINAL = True` refuses to build. Two further switches matter. `DRAFT_BANNER` shows the review banner and is turned off at launch. `MASTER_DRAFT_LIVE` adds the master draft page and its links once Project 2 deposits the master draft; fill `MASTER_DRAFT_DOI` and `MASTER_DRAFT_CHAPTERS` at the same time.
