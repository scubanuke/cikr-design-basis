Observed events, all sectors

The reference event register

A reference event reads a real event back through the design basis to ask whether the method was sufficient. This register lists every reference event in CIKR Design Basis Examples, Edition 2 (November 2026): 131 events across fifteen sectors, oldest first. Select a column heading to sort by it. Each event opens to a page of its own with what happened, the tier, each finding in a line, the annex written for asset owners, and the frozen public edition with its DOI. Nuclear events join at the edition nuclear enters the site.

The tier is the instrument's reading of whether the event shows all four marks of deliberate military action: intentionality, persistence, precision and denial. It is not a finding of who acted.
