A reference event reads a real event back through the design basis to ask whether the method was sufficient. Each one lives on its sector's page; this index lists them together, oldest first, so they can be read across sectors. It is generated from the same cards as the sector pages and is an index, not a second register: the tier shown is the reading frozen in CIKR Design Basis Examples, Edition 1 (November 2026), and each event's own entry, and the document behind it, is where the reading is made.
